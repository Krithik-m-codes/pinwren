---
title: Board
description: A kanban of every item by status — drag cards between columns, or move them from the keyboard.
---

Switch the inbox to **Board** with the **List / Board** toggle in the header (`/inbox?layout=board`; the older
`?view=board` still works). The board shows every item of the selected project, or of all projects — active and
closed — in one column per status (it ignores the status tabs; the other filters still apply):

| Open | In progress | In review | Resolved | Won't fix | Duplicate |
| ---- | ----------- | --------- | -------- | --------- | --------- |

Each card shows the screenshot thumbnail when the item has one, the title or first line, the page path, the number,
kind, priority, comment count, an attachment icon and the assignee.

## Moving cards

- **Drag** a card into another column to change its status.
- **From the keyboard**: focus a card with `Tab` and press `m` (or use the card's **Move to…** menu) to pick the
  column it moves to.

Viewers see the board read-only: cards can't be dragged and have no move menu.

A move is a normal status change: it writes a timeline entry, sends notifications and webhooks, closes or reopens a
linked GitHub or GitLab issue, and shows a toast with **Undo** (`u`).

Click a card (or press `Enter` on it) to open the item in a side sheet with the full
[detail panel](/docs/dashboard#list-and-detail).

## Board or list

The board is for seeing the shape of a review — how much is still open, what waits for review. Use the list for
triage: it has keyboard navigation (`j`/`k`), search, status tabs and bulk edits. Both read the same data, and the
URL remembers which one you used.

A [saved view](/docs/dashboard/saved-views) stores the layout with its filters, so a shared "This round" view opens
straight on the board.
